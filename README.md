# RDR II — Private Field Guide

یک شروع آماده برای دانشنامه خصوصی Red Dead Redemption 2 با تم تاریک، حساب جداگانه برای هر نفر و تأیید عضویت توسط مدیر.

## ساختار پروژه
- `index.html` — صفحه ورود و بخش‌های سایت
- `styles.css` — طراحی تیره با حال‌وهوای غرب وحشی
- `app.js` — رابط کاربری، جست‌وجو، ورود، علاقه‌مندی و انجمن
- `supabase-schema.sql` — جداول و قوانین امنیتی پایگاه داده

## معماری پیشنهادی رایگان
- **GitHub Pages** برای میزبانی فایل‌های سایت (رایگان، فقط فایل‌های استاتیک)
- **Supabase** برای حساب‌های کاربری، ورود امن، پروفایل‌ها و پیام‌های انجمن

GitHub Pages به‌تنهایی Python یا سرور اجرا نمی‌کند؛ این پروژه هم به Python نیاز ندارد.

## راه‌اندازی

### 1) ساخت پروژه Supabase
1. در https://supabase.com یک حساب بساز و یک پروژه جدید ایجاد کن.
2. از بخش SQL Editor، فایل `supabase-schema.sql` را کامل اجرا کن.
3. از بخش Project Settings → API، مقدار Project URL و کلید `anon` یا `publishable` را بردار.
4. این دو مقدار را در ابتدای `app.js` جایگزین کن:
   - `PASTE_YOUR_SUPABASE_PROJECT_URL`
   - `PASTE_YOUR_SUPABASE_ANON_KEY`

**کلید `service_role` را هرگز در فایل‌های سایت یا GitHub قرار نده.** فقط کلید عمومی anon/publishable مجاز است؛ امنیت داده‌ها با RLS برقرار می‌شود.

### 2) ساخت حساب مدیر
1. سایت را یک‌بار اجرا کن و با ایمیل خودت حساب بساز.
2. ایمیل را در صورت نیاز تأیید کن و وارد Supabase → Authentication → Users شو.
3. UUID حساب خودت را کپی کن.
4. در SQL Editor این دستور را با UUID خودت اجرا کن:

```sql
update public.profiles
set role = 'admin', approved = true
where id = 'YOUR-USER-UUID';
```

5. از سایت خارج شو و دوباره وارد شو. گزینه «مدیریت» ظاهر می‌شود.

### 3) دعوت دوستان
دوستانت از صفحه ساخت حساب، هرکدام حساب جداگانه بسازند. تا وقتی از پنل مدیریت تأییدشان نکنی، به محتوای داخلی و انجمن دسترسی ندارند.

### 4) انتشار روی GitHub Pages
1. یک مخزن GitHub بساز.
2. چهار فایل پروژه را در ریشه مخزن آپلود کن.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کن و branch اصلی و پوشه `/root` را ذخیره کن.
4. پس از انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.
5. در Supabase → Authentication → URL Configuration، آدرس سایت منتشرشده را به Site URL و Redirect URLs اضافه کن.

## نکات مهم امنیتی
- ثبت‌نام عمومی در صفحه ورود ممکن است، اما پروفایل جدید به‌صورت پیش‌فرض `approved=false` است.
- فقط مدیر تأییدشده می‌تواند اعضا را تأیید یا دسترسی‌شان را لغو کند.
- قوانین Row Level Security دسترسی به پروفایل‌ها و پیام‌ها را کنترل می‌کنند.
- محتوای نمونه دانشنامه در `app.js` قرار دارد و فعلاً اطلاعات نمایشی و خلاصه است؛ برای دانشنامه کامل باید مرحله‌به‌مرحله تکمیل شود.
- علاقه‌مندی‌ها در این نسخه فقط تا زمان تازه‌سازی صفحه در مرورگر باقی می‌مانند.
- عکس‌های پس‌زمینه از Unsplash بارگذاری می‌شوند؛ برای نمایش آن‌ها اینترنت لازم است.
- پروژه هواداری غیررسمی است. نام‌ها و علائم تجاری متعلق به صاحبانشان هستند.

## اجرای آزمایشی
برای آزمایش، بهتر است از یک وب‌سرور محلی استفاده کنی (مثلاً افزونه Live Server در VS Code)، چون `app.js` از ماژول JavaScript استفاده می‌کند.
